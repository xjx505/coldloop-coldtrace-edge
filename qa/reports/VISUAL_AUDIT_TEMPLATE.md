## Cross-screen findings

Evaluate the journey as a connected experience, not isolated images.

### Hierarchy
- Is connection/state obvious?
- Is temperature prioritized appropriately?
- Are technical values hidden until useful?

### Navigation
- Is the next action obvious?
- Do controls move unexpectedly?
- Does Back behave naturally?
- Is context preserved?

### Information density
- Any screen overloaded?
- Any important state hidden?
- Any unnecessary text?
- Any data that should be drill-down instead?

### Touch/phone ergonomics
- Tiny targets?
- Edge targets?
- bottom-nav/safe-area collisions?
- awkward scroll?

### Warning behavior
- Does normal look calm?
- Does watch/warning escalate appropriately?
- Is warning specific?
- Is recovery clear?

### Visual purpose
List any visual that does not clearly encode state, magnitude, trend, threshold, history, health, or action. These should be removed.
